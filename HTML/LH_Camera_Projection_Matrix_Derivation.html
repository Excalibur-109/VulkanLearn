0. 先固定约定

这三个函数看起来不同，但都只是把“目标坐标应该映射到哪里”写成方程，然后逐项填入一个 4x4 矩阵。先固定项目约定，符号才不会在转置、手性或深度范围上发生歧义。

存储行主序，matrix[row][column]
乘法列向量右乘：p' = M * p
LH 视空间相机前方是 +Z
ZO 深度near -> 0，far -> 1
p = (x, y, z, 1)T
M * p = (m00*x + m01*y + m02*z + m03, m10*x + m11*y + m12*z + m13, m20*x + m21*y + m22*z + m23, m30*x + m31*y + m32*z + m33)T

因此，C++ 构造函数的 16 个参数按“第 0 行、再第 1 行”的顺序写入。最后一列是与齐次分量 w=1 相乘的常数项；这正是观察矩阵中的平移，以及投影矩阵中的深度常数。

对应源码：Math/Matrix.hpp 中 Matrix 构造函数与相机/投影函数。

1. LookAtLH：把世界点写到相机坐标系

输入的 eye 是相机位置，target 是它观察的点。LH 版本要求观察方向成为视空间的正 Z 轴，因此先构造相机的三条单位基向量：

f = normalize(target - eye)
r = normalize(worldUp x f)
u = f x r

以相机为原点后的世界点是 p - eye。坐标变换的每一个输出就是这个向量在相机基上的投影：

xview = r . (p - eye) = r . p - r . eye
yview = u . (p - eye) = u . p - u . eye
zview = f . (p - eye) = f . p - f . eye
行向量如何出现将三个点积直接排成列向量右乘的行
1
xview = rxx + ryy + rzz - r . eye
它必须是矩阵第 0 行与 (x,y,z,1) 的点积。
2
yview = uxx + uyy + uzz - u . eye
同理得到第 1 行。
3
zview = fxx + fyy + fzz - f . eye
LH 前方为 +Z，所以这里保留 +f。
ViewLH 的三行就是 r、u、f 的点积展开；最后一行保留齐次坐标。

LookAtLH 的最终返回值

rxryrz-r.eyeuxuyuz-u.eyefxfyfz-f.eye0001
const Vector<T, 3> forward = NormalizeSafe(target - eye, {0, 0, 1});
const Vector<T, 3> right = NormalizeSafe(Cross(worldUp, forward), {1, 0, 0});
const Vector<T, 3> up = Cross(forward, right);

return Matrix<T, 4, 4>(
    right.x, right.y, right.z, -Dot(right, eye),
    up.x, up.y, up.z, -Dot(up, eye),
    forward.x, forward.y, forward.z, -Dot(forward, eye),
    0, 0, 0, 1);

2. PerspectiveLH_ZO：同时满足视锥、透视除法与深度端点

设垂直视场角为 theta，宽高比为 aspect。由相似三角形，边界点满足 y = z * tan(theta/2)。要让它除以 w 后刚好到达 NDC 的 y=1，先定义：

sy = cot(theta / 2) = 1 / tan(theta / 2)
sx = sy / aspect

透视的关键是让齐次坐标 clip.w = z。因为 LH 的前方 z 为正，前方点的 w 也为正。于是 clip.x=sx*x、clip.y=sy*y，透视除法后自然得到 ndc.x=sx*x/z、ndc.y=sy*y/z。

求 z 行的两个未知数ZO 深度要求近面为 0，远面为 1
1
clip.z = A*z + B,   clip.w = z
ndc.z = (A*z + B) / z
第 2 行负责 clip.z，第 3 行的 m32=1 负责 clip.w。
2
z=n: 0 = (A*n + B) / n   =>   B = -A*n
近平面的 NDC 深度目标是 0。
3
z=f: 1 = (A*f + B) / f   =>   A*f + B = f
远平面的 NDC 深度目标是 1。
4
A(f-n) = f   =>   A = f/(f-n)
B = -f*n/(f-n)
将第 2 步的 B 代入第 3 步即可。
把 A、B 放入第 2 行；把 1 放入 m32，投影矩阵的所有非零元素就确定了。

PerspectiveLH_ZO 的最终返回值

sx0000sy0000f/(f-n)-fn/(f-n)0010
P * (x, y, z, 1)T = (sxx, syy, f/(f-n) * z - fn/(f-n), z)T

z=n => ndc.z=0
z=f => ndc.z=1

源码中 inverseDepth = 1 / (farPlane - nearPlane)，所以 output[2][2] = farPlane * inverseDepth 就是 A，output[2][3] = -farPlane * nearPlane * inverseDepth 就是 B。

3. OrthographicLH_ZO：三个一元线性映射拼成矩阵

正交投影不需要透视除法，齐次 w 始终为 1。分别令 x、y、z 做一次“区间映射到目标区间”的仿射变换即可：

xndc = axx + bx, [left,right] -> [-1,1]
yndc = ayy + by, [bottom,top] -> [-1,1]
zndc = azz + bz, [near,far] -> [0,1]

X/Y 的系数

ax*left + bx = -1
ax*right + bx = 1

ax = 2/(right-left)
bx = -(right+left)/(right-left)

把 left/right 换成 bottom/top 就得到 y 行。

LH ZO 深度的系数

az*near + bz = 0
az*far + bz = 1

az = 1/(far-near)
bz = -near/(far-near)

这里没有除以 z；它与透视投影共享的只是 ZO 的端点目标。

OrthographicLH_ZO 的最终返回值

2/(r-l)00-(r+l)/(r-l)02/(t-b)0-(t+b)/(t-b)001/(f-n)-n/(f-n)0001

此矩阵直接由 return Matrix<T, 4, 4>(...) 返回，16 个参数仍按行写入。最后一行是 (0,0,0,1)，所以 TransformPoint 不会额外改变 x/y/z 的比例。

4. PerspectiveVulkanLH_ZO：只翻转裁剪空间 Y

新增函数先完整复用 PerspectiveLH_ZO，然后将 output[1][1] 取反。普通 LH 投影的这一项是 sy，因此 Vulkan 版本的差异只有：

clip.y = sy*y   ->   clip.y = -sy*y
ndc.y = clip.y / clip.w   ->   -ndc.y

clip.x, clip.z, clip.w 不变

PerspectiveVulkanLH_ZO 的最终返回值

sx0000-sy0000f/(f-n)-fn/(f-n)0010
template <FloatingScalar T>
inline Matrix<T, 4, 4> PerspectiveVulkanLH_ZO(
    T verticalFovRadians, T aspectRatio, T nearPlane, T farPlane) noexcept {
    Matrix<T, 4, 4> output =
        PerspectiveLH_ZO(verticalFovRadians, aspectRatio, nearPlane, farPlane);
    output[1][1] = -output[1][1];
    return output;
}
不要翻转两次Vulkan 的 Y 方向也可以通过负高度 viewport 处理。当前函数选择在投影矩阵中翻转，调用方应与后端的 viewport 策略保持一致；同时翻转投影和 viewport 会把图像再次翻正，导致约定不一致。

Y 翻转不改变 LH/RH，也不改变 NDC 深度范围。手性仍由观察矩阵和 clip.w=+z 决定，ZO 深度项仍是 f/(f-n) 与 -fn/(f-n)。

5. 代入检查：每个返回矩阵应该满足什么

函数代入输入期望输出原因
LookAtLHp = eye(0,0,0,1)每一行都是 basis . (p-eye)。
LookAtLHp = targetz > 0target 在 LH 相机的前方，即 +Z。
PerspectiveLH_ZOz=nearndc.z=0深度方程的第一个边界条件。
PerspectiveLH_ZOz=farndc.z=1深度方程的第二个边界条件。
OrthographicLH_ZO(left,bottom,near)(-1,-1,0)三个区间映射的左端点。
OrthographicLH_ZO(right,top,far)(1,1,1)三个区间映射的右端点。
PerspectiveVulkanLH_ZO(0,y,z,1)ndc.y 符号相反仅 m11 被取反，z/w 保持不变。
阅读源码时的快速定位LookAtLH 的最后一列来自 -Dot(basis, eye)；PerspectiveLH_ZO 的 [2][2]、[2][3] 来自近远平面方程；OrthographicLH_ZO 的每一行都是一个区间的仿射映射。理解这三点，返回矩阵的每个非零元素都可以自己重新得到。
